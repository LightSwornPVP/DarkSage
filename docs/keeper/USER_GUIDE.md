# User Guide

Home summarizes the active project, runs, approvals, findings, and providers.
Projects inspects Git identity, worktrees, status, branch, and HEAD. Tasks captures
scope, baseline, risk, permitted/prohibited actions, validations, reviewers, and
completion criteria. Authorizations creates short-lived scoped authority.

Workflow, Findings, and History expose persisted stage, review, command, artifact,
and report records. Settings displays diagnostics and configured executable paths.
Use the mock demonstration to verify author, audit, repair, post-repair review,
final verification, and completion without changing a real repository.
