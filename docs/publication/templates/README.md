# Publication Page Templates

Markdown authoring scaffolds for the thirteen page types defined in [DSF-001 §E.1–E.13](../DARKSAGE_PUBLICATION_ARCHITECTURE.md#e-page-systems) and elaborated in [DSF-003 §4–§9](../DARKSAGE_VISUAL_DESIGN_SYSTEM.md). Each file is a template only — it defines structure and `{{placeholder}}` fields for a future generation tool, not a rendered page. No template introduces a page type, palette value, or component name beyond what DSF-001/DSF-003 already define.

| `12-GlossaryIndex.md` | E.12 Glossary / Index Page |

Thirteen files for thirteen page types — matches DSF-001 §E exactly, including its combining of Glossary and Index into one page type (`12-GlossaryIndex.md`). No file here creates a fourteenth page type.
