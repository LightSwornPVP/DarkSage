# DarkSage Publication State and Promotion Package

This package defines the publication state register, promotion rules, evidence requirements, and expansion publication index for the DarkSage codex.

The files in this package are:

- `PUBLICATION_STATE_REGISTER.csv`
- `PUBLICATION_PROMOTION_RULES.md`
- `EXPANSION_PUBLICATION_INDEX.md`
- `PUBLICATION_EVIDENCE_REQUIREMENTS.md`
- `PUBLICATION_CHANGELOG.md`

This package distinguishes released Core volumes from draft expansion volumes and defines the controlled requirements for release promotion.
